# dotfiles

Personal configuration files for macOS and zsh.

## Contents

- `.zshrc` — shell aliases, prompt, and history settings
- `.gitconfig` — global git aliases and user info
- `.vimrc` — editor tweaks
- `bin/` — small helper scripts

## Install

Symlink files into your home directory:

```bash
./install.sh
```

## Notes

- Uses Homebrew for package management.
- See `docs/` for environment-specific setup.
